# Security scope

ConsentDiff is an implemented local reference lab. It operates on fictional file-sharing state generated by its own application. It does not interact with external accounts, send invitations, process payments, or call other websites.

## Implemented boundary

The server binds to loopback at 127.0.0.1. It validates the Host header, rejects supplied foreign Origins on writes, accepts JSON bodies with a size limit, and serializes experiment operations. Static resources have a restrictive content policy and are served locally.

These controls support a local development tool. There is no user authentication, tenant isolation, TLS deployment, or authorization system for a public service. Do not expose the server through port forwarding or treat it as a hosted product.

## Fixtures and drivers

Human and tool paths use separate SQLite stores with synthetic recipients, plans, approvals, and effects. The fast runner calls controllers directly; the browser runner uses visible Chrome controls paired with HTTP or actual native WebMCP. It blocks browser requests outside its one owned loopback origin. Driver and evidence capabilities are separate, and backend finalization recomputes effects from its own databases.

Approval tokens, identity, time, and scheduling are fixtures, not cryptographic or production authentication mechanisms. The fixed file-sharing intent is not an authorization to perform real actions.

## Observer independence

The observer uses a separate read-only SQLite connection and reads actual grants/effects. It is logically independent of a success message but shares the local machine and codebase.

A malicious operator with control over the application, observer, and evidence can defeat that assumption. The project does not claim remote attestation or reliable proof about a hostile production website.

## Evidence handling

Saved evidence includes fictional identities, fixed fixture approval tokens, traces, before/after observations, and final application databases. The synthetic tokens have no external authority. Do not replace these fixtures with real credentials or customer records.

Controller exports contain a fresh replay checked against repeated-run output. Browser exports retain the actual databases, captures, receipts and screenshots from every repeat. A modified runner can fabricate capture metadata: this is internal correlation within one trusted local environment, not remote attestation. Hash manifests detect changes relative to their contents but are unsigned; rewriting both manifest and content is outside the authenticity guarantee.

## Temporary interactive sessions

The manual demo uses temporary state separate from saved cases. Sessions are bounded and old sessions can be evicted. They are removed when the local server closes. Do not rely on the demo session as durable evidence; run a saved paired experiment when a retained record is required.

## Cancellation semantics

The implemented contract concerns cancellation before commit. It does not promise rollback of completed external operations. In the safe fixture, approval must match the exact current plan; a changed role requires new approval.

The tester does not retry a cancelled real-world operation because it never performs one. Retry examples concern a single synthetic operation identity.

## Future integrations

A future external-application or service adapter would need reviewed permissions, isolated accounts, explicit effect observation, redaction, and retention controls. Screenshots, accessibility trees, and traces may contain sensitive data in such systems. Those integration requirements are not satisfied merely by the local prototype.

See [BROWSER_INTEGRATION.md](BROWSER_INTEGRATION.md) for the delivered browser boundary and [INTEGRATION_ROADMAP.md](INTEGRATION_ROADMAP.md) for remaining external-application work.

## Claims

A pass supports the tested fictional journey and contract. It does not certify legal consent, prove agent safety, test arbitrary websites, or establish that no undiscovered defect exists. Unknown evidence remains inconclusive.
